# Stage 1: IQ16 candidate and automatic chunk selection

Added `quant16<TYPE>` for IQ3_XXS (GGML type 18), IQ3_S (21), and IQ4_XS (23). IQ3 headers require two-byte alignment; packed loads respect that alignment instead of assuming every block is four-byte aligned.

This stage also introduced automatic prefill chunk selection within the available VRAM budget while retaining explicit chunk overrides. CPU oracle checks and benchmark details are recorded in the adjacent JSON/log artifacts.
