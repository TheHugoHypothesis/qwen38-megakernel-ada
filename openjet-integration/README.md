# Open-Jet integration source snapshot

These files are the Open-Jet-side integration used alongside `megakernel/`: the CUDA engine build manifest, GGUF compatibility detection, server configuration, and focused tests. They are copied as complete source files from the working Open-Jet tree so the integration can be reviewed and ported. They are not a standalone Open-Jet checkout; apply/reconcile them against the upstream project revision linked in the top-level README.
